# EclipseCam agent work queue

The canonical product contract is `PRODUCT.md`. The umbrella program is GitHub issue #1.

Independent implementation issues are organized so multiple agents can work in parallel with minimal file overlap:

- Scientific local circumstances and validation
- Observer guidance and GPS integration
- Device orientation and readiness
- CameraX preview and capability inventory
- AR trajectory and framing
- Automated capture service
- Google Maps path experience
- Local gallery and media rendering
- Accessibility, localisation, privacy, and release quality

Agents must claim an issue, use a dedicated branch, respect declared dependencies, and open a PR with tests and validation evidence. See `CONTRIBUTING.md`.
