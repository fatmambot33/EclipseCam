# Agent handoff checklist

Before handing work to another agent:

- Link the GitHub issue and pull request.
- State the current branch and latest commit.
- List completed acceptance criteria.
- List remaining criteria and blockers.
- Record test commands and results.
- Record any physical-device test still required.
- Identify account-owned secrets or Play Console work without exposing values.
- Never describe unfinished scientific or capture behavior as production-ready.
