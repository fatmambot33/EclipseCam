# AR overlay completion checklist

- Deterministic world-to-screen projection: automated JVM tests.
- Contact markers and trajectory arc: `EclipseTrajectoryOverlay`.
- Portrait, landscape, and selected field of view: projection contract tests.
- Full-event fit result: `FramingAssessment.fit` status chip.
- Directional guidance: assessment message displayed in the preview.
- Low-confidence handling: unavailable state with no marker coordinates.
- Overlay snapshot coverage: deterministic semantic presentation snapshots.
- Pixel 7 Pro verification: repeatable outdoor release protocol.
